# Bounded Autonomy and Guardrails with Claude and Claude Code

This repository contains a hands-on learning project and course materials focused on building AI-assisted developer workflows with bounded autonomy, guardrails, and structured agent patterns using Claude and Claude Code.

## Overview

The project combines:

- lesson-based learning modules
- demo implementations
- exercise starter and solution code
- a final project scaffold for building an autonomous but controlled AI coding workflow

## Getting Started

1. Install dependencies from the project root:

```bash
npm install
```

2. Navigate to a lesson or the project starter folder you want to run.

3. Follow the README in the specific module for setup and execution instructions.

## Main Project

The `project` folder contains the final starter implementation for the capstone work, including scripts, config, and tests.

## Learning Goals

- Understand model selection and reasoning tradeoffs
- Use extended thinking and agentic patterns responsibly
- Build guardrails around autonomous agent behavior
- Integrate MCP tools, structured outputs, and custom tooling
- Evaluate agent quality and reliability
